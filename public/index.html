Request

Type any request. The Pipeline Runner asks the LLM for an agent specification, checks the Agent Pool, and calls the Agent Factory only on a miss. Predefined agents may read agent_events. Dynamic agents are blocked.

Ctrl+Enter runs the pipeline.
